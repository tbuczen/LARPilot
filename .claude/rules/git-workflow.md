# Git workflow

- When a fix or feature is complete (code written, quality tools and
  relevant tests passing), always open a pull request for it automatically
  — do not wait to be asked each time. Push the change on its own
  branch off the latest `main` and open the PR against `main`.
- One PR per unrelated piece of work. Don't stack an unrelated fix onto a
  branch/PR that already exists for something else.
